## 2026-09-04 ｜ V1.0 前端原型初始化

- **技术栈**：Vue 3 + Vite + Pinia + Naive UI + ECharts，纯前端 Mock 数据。
- **功能模块（6 大模块）**：
  1. 账号与组织
  2. 岗位与候选人
  3. 面试管理（核心，InterviewRoom 实现 AI 流式对话 + 双模交互）
  4. 题库管理
  5. 评估报告
  6. 数据统计
- **版本控制**：首次提交 `51c4b00`（feat: 初始化 AI 智能面试平台原型 V1.0），含 33 文件 / 6738 行；`.gitignore` 排除 `node_modules/`、`.trae/`、`dist/`。

## 2026-09-04 ｜ V3.0 求职者端（c-portal）

- 新增求职者端独立门户（布局 `CandidateLayout` + 独立路由与 Pinia store），与企业端隔离。
- 关键页面：求职登录/注册、模拟面试配置（MockConfig）、模拟面试房间（MockRoom）、我的面试、能力档案、设置。

## 2026-09-04 ｜ AI 改简历 / 简历测评（前端）

- 求职者端新增工作台（Workbench），聚合「AI 面试 / AI 改简历 / 简历测评」三大入口，/c 默认进入工作台。
- **改简历（ResumeEdit.vue）**：按「摘要 / 项目经验 / 技能栈」分段流式输出优化文案，原文 vs 优化后对比，附修改理由，支持逐段 / 一键应用。
- **简历测评（ResumeAssess.vue）**：6 维雷达图（匹配度 / 完整性 / 结构性 / 亮点度 / STAR / 关键词）+ ATS 关键词命中报告 + 改进清单。
- 导航调整为：工作台 | AI 面试 | AI 改简历 | 我的面试 | 能力档案 | 设置。

## 2026-09-05 ｜ 后端接入 MySQL（全栈打通）

- **技术栈**：Node.js + Express + mysql2（连接池）+ JWT + bcrypt；ES Module。
- **数据库**：库名 `ai_interview`，5 张表 —— `candidates`、`resumes`、`positions`、`mock_interviews`、`org_users`；JSON 列存雷达图 / 技能 / 项目。
- **能力**：
  - 启动自动建库、建表、幂等灌种子（求职者 陆星河、2 份简历、4 条面试；企业 林舒豪；6 条岗位）。
  - 接口：注册/登录/me（JWT 鉴权）、岗位列表、面试记录列表/新增、简历列表、简历测评、AI 改简历。
- **前端接入**：Vite 加 `/api` 代理到 `:3000`；封装 `src/api/client.js`；store 登录/注册走真实 API，**后端不可用时自动回退 Mock**，界面不崩。
- **安全**：MySQL 密码仅存 `server/.env`（已 gitignore），不硬编码、不入库。
- **踩坑**：MySQL JSON 列经 mysql2 已自动解析为对象，重复 `JSON.parse` 会抛错被静默吞掉，导致岗位名丢失 → 改为按类型判断。

## 2026-09-05 ｜ AI 改简历 / 测评后端化

- **测评服务（services/assess.js）**：按简历解析数据实时计算 6 维评分 + 关键词命中 + 改进清单（综合分 68 验证通过）。
- **改简历服务（services/resumeOptimize.js）**：强结构化 JSON 输出（`section/original/optimized/rationale`），生成摘要三段式、项目 STAR 重构、技能按领域分组并补 ATS 高频词。
- **设计原则（复盘）**：AI 输出与「应用」解耦 —— 后端只产出分段建议，前端显式「应用/一键应用」，避免整份覆盖不可控。

## 2026-09-05 ｜ 本地简历文件上传 + AI 智能修改

- **依赖**：新增 `multer`（上传）、`pdf-parse`（PDF 解析）、`mammoth`（Word .docx 解析）。
- **上传链路**：
  - `POST /api/c/resumes/upload`，字段名 `resume`，`multipart/form-data`。
  - multer `diskStorage` 落盘 `server/uploads/`（已 gitignore）；`fileFilter` 限定 PDF/Word/TXT/MD；`limits` 10MB。
  - 提取纯文本 → 启发式结构化（技能词典命中、年限/学历正则、项目行抽取）→ 写入 `resumes` 表（新增 `file_name/file_path/raw_text` 字段，带幂等迁移）→ 返回新简历。
- **前端**：改简历页新增「📄 上传简历文件」按钮（隐藏 file input），上传成功后自动选中新简历并**直接触发 AI 优化**；展示解析摘要（识别技能数/年限）。
- **解析器迭代**：
  - 工作年限正则兼容「6 年前端开发经验」（年与经验间有词），用 `(?<!\d)(\d{1,2})(?!\d)` 排除 2020/2021 年份误匹配。
  - 技能去重：剔除被更长词包含的短词（Java 误命中于 JavaScript、Vue 命中于 Vue3）。
- **验证结果**：txt 上传 200，识别 14 个技能 / 6 年经验 / 本科学历 / 3 个项目；非法类型 .exe → 400；缺文件 → 400；新简历可正常 AI 优化（3 段）。
